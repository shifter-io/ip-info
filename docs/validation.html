What was verified

  • Real September 14 MMDB copied locally; SHA-256 matches the source manifest. The 1.3 GB file is ignored by Git and is not served publicly.
  • Exact documented example match, nullable fields, IPv6, IPv4-mapped IPv6, input errors, CORS, no-store responses and forged forwarding headers.
  • Independent Python MMDB comparisons passed for five IPv4/IPv6 addresses.
  • Formatting and Clippy with warnings denied passed. OpenAPI/field references, sitemap, metadata, structured JSON and internal links passed validation.
  • Desktop/mobile appearance visually inspected, including 320 px and 390 px widths. Keyboard, copy controls, no-JavaScript form submission and direct-file documentation navigation passed.
  • Analytics tests intercepted Google requests locally: no pre-consent traffic, rejection respected, allowed events sanitized, withdrawal removes the loader/cookies and reloads safely. No events were sent to a real GA4 property.
  • Read-only non-root container, liveness/readiness and corrupted-database behavior tested. Invalid MMDB returned readiness/lookup 503 while liveness remained 200. Graceful shutdown exited 0 without an OOM.

Container compatibility

The final Linux amd64 image passed local API/page smoke checks under local emulation. Image ID: sha256:1115aa4d776a3eb94c237c99a331954961c7a009eba92269ba42b1a0ba5ce447. Its size is 1,427,216,688 bytes including the licensed database. It is available locally as ip-info:amd64; no image was pushed to a registry.

Measured resource use

Native Linux arm64 container on the local Mac’s Docker engine, capped at 1 CPU and 2 GiB. A Python client issued 20,000 distinct mixed IPv4/IPv6 lookups per pass using 16 workers and persistent HTTP connections.

Peak cgroup memory was 897.2 MiB. After the warm run, anonymous memory was 1.2 MiB and file-backed memory was 891.2 MiB. The native release binary was approximately 3.7 MB; the private image is approximately 1.45 GB because it contains the MMDB.

These are local measurements, not a throughput guarantee or production sizing proof. The first pass was not guaranteed OS-cache-cold. The load generator, container networking and other local work affect latency. Use 2 GiB as the initial deployment budget and measure representative traffic before reducing it.
