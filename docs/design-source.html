IP Info adaptations

The original React components are expressed in standalone HTML, embedded CSS and small browser scripts. The Rust API and deployment architecture are preserved. The homepage prioritizes actual IP lookup, nine integration languages and agent documentation. It does not inherit proxy pricing, customer counts, analytics IDs, tracking code or unrelated marketing claims.

Core content stays visible without JavaScript. Reduced-motion preferences disable animation, and keyboard focus reveals any section waiting for a scroll animation.
